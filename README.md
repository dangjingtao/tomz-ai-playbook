# tomz-ai-playbook

Tomz 的 AI 协作技能库。

这个仓库以 **skills 为主**：把已经验证过、值得复用的工作流、操作约定和检查清单固化下来，让后续协作尽量少重复解释。

## 目录

- `skills/`：主要内容。可复用的发布、迁移、部署、学习、写作与检查技能。
- `knowledge/`：长期专题的知识状态与进度；记录「已经学到/做到哪里」，不复制正文。
- `memory/`：长期协作记忆的保留位置。默认谨慎，宁缺毋滥。
- `scripts/`：确实值得自动化时再加入脚本。
- `templates/`：需要稳定复用的模板。

## 原则

1. **技能优先，记忆克制。** 能写成工作流的，不写成人物档案。
2. **知识与记忆分开。** 学习进度、专题状态放 `knowledge/`；只有稳定协作约定才考虑 `memory/`。
3. **不提交秘密。** API key、token、密码、cookie、私钥等永远不进入仓库；只允许记录 Secret / 环境变量的名称。
4. **不囤私人材料。** 不复制私人聊天全文、邮件正文或其他与技能无关的私密内容。
5. **默认可验证。** 技能尽量写清楚目标仓库、入口、成功条件和回退方式。
6. **以当前仓库事实为准。** 真正执行前仍应读取目标仓库的最新配置，避免旧约定覆盖新事实。

> 当前仓库为公开仓库，因此 `memory/` 只允许保存明确适合公开、且对长期协作有价值的信息。
