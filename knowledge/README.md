# Knowledge

这里记录长期协作中形成的 **知识状态与进度**：我们已经学到哪里、哪些专题已经存在、下一次应该从哪里继续。

它和另外两个目录的边界：

- `skills/`：告诉 AI **怎么做事**。
- `knowledge/`：告诉 AI **已经学到/做到哪里**。
- `memory/`：只保留少量、稳定、适合长期公开保存的协作约定。

## 原则

1. 只记录对继续工作真正有帮助的状态，不复制文章全文。
2. 不记录 API key、token、私人聊天原文或不适合公开的信息。
3. 状态可能过期；执行前仍应检查目标仓库和最新内容。
4. 当新的学习或写作进度被确认后，可以更新这里，而不是依赖模糊记忆。
