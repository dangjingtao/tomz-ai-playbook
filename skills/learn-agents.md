# 一起来学智能体

## 何时触发

当 Tomz 说「一起来学智能体」「继续学智能体」「继续 Agent 学习」等近似表达时，默认使用本技能。

## 目标

把智能体学习做成一个长期、连续、可验证理解的学习过程，而不是一次性问答或机械按章节读书。

## 默认学习主线

- 主要参考：`datawhalechina/hello-agents`
- 默认路线：**4 → 7 → 9 → 10 → 12 → 14**
- 第 1–3 章按需要回补，不要求为了“完整”而先顺读。

执行前应检查上次学习进度；不要在已有进度时重新从「什么是 Agent」开始。

## 学习方式

1. 先确定当前进度和本次要解决的问题。
2. 用日常语言解释核心概念，但保留关键技术细节。
3. 不只讲定义，要用具体例子、代码路径或行为链路解释。
4. 适时追问，确认 Tomz 是否真的理解，而不是只问「懂了吗」。
5. 优先把概念与 **Mira 的实际开发**联系起来：哪些能直接用、哪里有坑、怎样验证。
6. 一次学习结束后，记录清楚：学了什么、还没解决什么、下一步从哪里继续。

## 输出与发布

「一起来学智能体」是 Mira 站上的长期专题：

- 站点：`https://mira.tomz.io`
- 仓库：`dangjingtao/uichat-mira-docs`
- 专题目录：`agent-learning`
- 分组名：`一起学智能体`
- 文章按专题连续编号。

只有用户明确要求发布/整理成博客时才写博客；学习过程本身不必为了产出文章而打断。

## 检查点

- 是否延续了已有学习状态，而不是重开。
- 是否包含理解验证，而不只是讲解。
- 是否尽量联系 Mira 的真实开发。
- 如果发布，是否进入 Mira 老站而不是 `tomz.io` 主站。

## 安全与事实边界

- 不把 API key、token、私人聊天内容写入学习资料。
- 章节、仓库结构或项目现实可能变化；真正执行前读取最新仓库状态，以当前事实为准。
