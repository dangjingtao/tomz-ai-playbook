# Skills

这里存放经过实际协作验证、值得复用的操作技能。

## 已有技能

- `dispatch-task-card.md`：派卡前补齐可信项目上下文，避免施工线程只拿任务卡就开工。
- `learn-agents.md`：一起学习智能体相关内容时的协作流程。
- `publish-blog.md`：博客发布与站点映射约定。
- `write-bible-notes.md`：读经札记整理与发布约定。

## 写法建议

每个技能尽量包含：

- **何时触发**：用户用什么说法时默认采用该技能。
- **目标**：最终要达成什么。
- **默认映射**：仓库、站点、路径等稳定约定。
- **执行步骤**：优先通过可用工具直接完成，只有确实需要时才让用户手工操作。
- **检查点**：怎样确认真的成功。
- **安全边界**：哪些内容不能写入仓库或日志。

技能不是死代码。执行前仍应读取目标仓库的最新状态；如果仓库现实与技能文档冲突，以当前事实为准，并在必要时回写更新技能。
