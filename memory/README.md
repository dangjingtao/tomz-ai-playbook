# Memory

这里是长期协作记忆的**保留位置**，不是默认写入区。

当前仓库是公开仓库，因此这里采用更严格的规则：

## 可以记录

- 明确适合公开的长期协作约定。
- 稳定的项目映射、公开站点关系、公开工作流偏好。
- 用户明确要求长期保留，且公开无风险的信息。

## 默认不记录

- 私人经历、关系、身份细节、健康、财务等个人敏感信息。
- 私人聊天、邮件、日历内容或其大段摘要。
- API key、token、密码、cookie、私钥、恢复码等任何秘密。
- 仅仅“可能以后有用”的零散信息。

## 写入原则

1. **先问价值，再问必要性。** 对未来协作没有明确价值，就不写。
2. **能放 skills 就不放 memory。** 操作习惯优先固化为技能。
3. **最小化。** 只记录完成协作所需的最少事实。
4. **用户控制。** 用户要求删除、修改或不再记录时，应优先执行。
5. **公开仓库限制优先。** 任何不确定是否适合公开的信息，都不要写进这里。

如果未来仓库改为 Private，也不意味着可以放 Secrets；秘密仍应只存在于 GitHub Secrets、密码管理器或其他专门的秘密存储中。
